Rollout monitor

Three live cameras. With this browser tab focused, press c to start, Space to pause or resume, v to record a synchronized video, d to start or end a demo-format episode (robot state, actions and full camera frames, about 4–5 GB per minute), and r to return YAM to home and then to the ready state. With auto-record on, every Start records an episode and its video; Reset, a model change or a camera reconnect ends it, and the label form opens with the checkpoint and W&B run already filled in. Reconnect cameras pauses control without closing the rollout. The overlay is visual only.
