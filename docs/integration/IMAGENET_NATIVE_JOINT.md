# ImageNet native joint adapter

This adapter trains the native joint MoT image expert on independent ImageNet-1K images. The complete joint architecture remains constructed: 314,227,000 parameters with QK normalization, RMSNorm and SwiGLU. The `imagenet` embodiment has no pose, action or camera-vector bank; only image patches and the shared Qwen projection execute, covering 159,006,592 parameters. Dormant parameters remain in the model and checkpoint. DDP must enable `find_unused_parameters`.

Select `+experiment=pixel_proprio/native_joint/imagenet_image_generation` with the maintained `train_zarr_cartesian` entry configuration. Every data path and digest is mandatory and initially unbound. The model uses the same 1024-wide image expert, eight blocks, eight heads, 128-wide language projection, and retained EVA/human vector banks as the paired Elmo architecture. The explicit optimizer controls are AdamW peak LR 5e-6, 3,000-update linear warmup then constant LR, weight decay 0.01, no clipping, seed42, four ranks with eight images per rank and 300,000 total updates. These controls must appear in the resolved launch preflight.

Each input is one actual image at camera0/time0, represented by 100 raw RGB patches of width768. Decode applies EXIF orientation, RGB conversion, bicubic resize of the shorter side to160 using round-half-up dimensions, and a centered160 crop with integer-floor origin. Pixel scaling and row-major HWC patchification use the existing native `[-1,1]` path. There is no random augmentation, latent image encoder, fabricated vector stream, class-ID embedding, clean initial frame, fused loss or CFG. Training retains the native independently sampled uniform noise level and plain FP32 x0 MSE. The spatial patch attention remains active; temporal and cross-modal interactions are unexercised for this source.

An explicit class catalog maps each of the 1,000 WNIDs to its exact class-name text. The existing frozen Qwen3-Embedding-0.6B revision produces1024-dimensional unit vectors. The class manifest binds catalog bytes, cache bytes, complete encoder provenance and each class-name/vector hash; features enter the unchanged shared1024→128 language path. Authoring a metadata manifest does not prove that actual Qwen inference occurred. That proof belongs to the allocated producer and retained model-weight provenance.

Allocated CPU preparation uses `scripts/data/prepare_imagenet_imagefolder.py` with `class-language`, `image-inventory` and `validation-anchors` modes. Preparation inventories every admitted image with exact byte size and SHA256. The image-inventory command does not decode every image; a separate allocated all-image decode receipt is mandatory before data admission. It rejects symlinked split/class/image paths and unknown split-root sidecars. Source aliases and the two historical ImageNet train extraction scripts must be handled explicitly in the actual preparation receipt, never silently counted as images. Production configuration requires1,281,167 train images and50,000 official validation images. The small test fixture explicitly substitutes two classes and its actual counts.

The validation-anchor manifest binds the entire official validation inventory and chooses exactly one image per WNID by the first sorted relative image key. Thus scheduled validation uses1,000 frozen official-validation anchors, never TRAIN images. The full50,000-image validation inventory remains part of the immutable data context and stays excluded from training. Validation uses fully noisy input and the actual native20-step sampler; it rejects nonfinite values for every generated RGB pixel and aggregates normalized paired-reference MSE. This MSE is a class-conditioned paired diagnostic, not official FID or a perceptual-quality benchmark. The existing diagnostics save a fixed first32 previews from canonical anchor order on rank0; with the configured four-rank contiguous shards, rank0 owns the first250 anchors. The preview JSON retains source keys, class/feature hashes, pixel metadata and generated/target diagnostics. It writes PNG rather than a fictitious one-frame video.

Training draws images uniformly with replacement through the maintained global rank-slot sampler. Acknowledgement advances only after a consumed training batch; worker prefetch never commits the cursor. Validation shards entire batches without padding or dropping and uses global validation-batch identities for deterministic sampling. The data context binds all source, split, preprocessing/Pillow, class-language, anchor and topology identities and is checked exactly on resume. Its offline loader restores metadata without opening raw image splits.

Checkpointing and validation are scheduled every20,000 updates, retaining all15 immutable epoch+step milestones and a `last.ckpt` symlink. There is no extra terminal production save. At global batch32, 300,000 updates cover9.6million image draws, about7.49 ImageNet train epochs. This is a shared-architecture image-versus-video diagnostic; it does not reproduce the JiT image-training budget or isolate dataset coverage from temporal prediction difficulty.
