# Source-pinned numerical parity

The reference archives in `tests/fixtures/legacy_pipeline/` were generated by
executing the actual EgoVerse data and metric implementations at commit
`ec5c903c067bf1b29bbff781bc414c6df2bcf1f2`. They are not graph outputs relabeled
as legacy references. Every archive has a metadata sidecar with its SHA-256,
source revision, transform arguments, selected indices and normalization count.

The ten cases cover Cartesian EVA, Aria, Mecka and Scale in camera and wrist
frames, plus Aria's retained 138D MANO keypoints in head and wrist frames.
Each source contains three deterministic, 48-frame episodes with translating
and rotating poses. The normalization sample contains 54 frames, selected
with fraction 0.37 and seed 42. Five samples include interior, terminal and
next-episode indices. The comparisons cover:

- model-facing keys, dimensions, image routing and transformed poses/actions;
- normalization statistics and quantile, min/max and z-score round trips;
- paired and final MSE, Gaussian Fréchet summaries and three-sample reverse KL.

`scripts/integration/reference_probe.py` supports the two source APIs and checks
that imports come from the requested checkout. It does not replace transforms,
normalizers or metric implementations. The legacy process used the graph CPU
environment's numeric packages plus the real `projectaria-tools==2.0.0` SE3
library, installed separately to match the legacy lock. The exact wheel and
hash are recorded in `evidence/legacy-probe-environment.json`. This is a data
and metric comparison, not a reproduction of the legacy training environment.

To regenerate references, create the source checkout at the revision above,
generate fresh inputs with `tests.fixtures.synthetic_episodes.write_moving_episode`
for seeds 0, 1 and 2, and run the probe with that checkout on `PYTHONPATH`:

```bash
source emimic/bin/activate
PYTHONPATH=/absolute/legacy-checkout:/absolute/legacy-optional-libraries \
  python /absolute/graph-checkout/scripts/integration/reference_probe.py \
  --root /absolute/new-fixture-root --source-root /absolute/legacy-checkout \
  --vendor eva --representation cartesian --frame camframe --api legacy \
  --output /absolute/new-reference-directory/eva-cartesian-camframe.npz
```

The output must be new; the probe refuses to overwrite existing archives or
metadata. Generate all ten cases before replacing reviewed references. Graph
regression tests regenerate the episodes and compare directly with the checked-in
archives. Non-image tolerances are 2e-6 absolute and 2e-5 relative, accommodating
floating-point pose conversion. JPEG pixels allow one quantization unit.

`tests/fixtures/legacy_language_schedule.json` separately records all 2,001
learning rates from the source warmup/cosine function. Both retained Qwen
recipes now resolve their actual optimizer and scheduler and match that series.
The constructor gate also builds each model wrapper and its configured
optimizer/scheduler, which catches references that network-only audits miss.

The investigation repaired camera-frame MSE semantics at angle wraparound:
the retained root evaluator uses plain source MSE; existing graph campaigns
keep their explicit/default wrapped metric behavior. It also repaired the
shared tempo evaluator's video lifecycle and sparse-video upload FPS.

Retained root models now declare their expected preprocessing state in
`model.data_requirements`. Generic code compares that declared subset before
model construction and includes it in checkpoint/artifact compatibility hashes.
The keypoint wrist recipe has a separate frame declaration while sharing the
same architecture. These declarations cover the restored root recipes, not
every preexisting nested campaign; the latter still require review.

This evidence does not establish real-weight GPU training, all model-output
parity, or assembled-destination correctness. Those remain separate gates.
