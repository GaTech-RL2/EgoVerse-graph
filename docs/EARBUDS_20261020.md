# Earbuds absolute-duration ARC and standard DP

These two fresh runs share the frozen `abc_arc/earbuds_20261020` dataset:
285 previously selected episodes plus 49 usable October 20 episodes. The
requested 50-episode collection contains one incomplete episode, `demo_83`,
which is excluded. The canonical operator-stratified split uses seed 42:
317 training and 17 validation episodes.

| Recipe | Model | Native prediction |
| --- | --- | --- |
| `yam_arc_grid/earbuds_20261020_absdur` | HPT300 and flow, absolute per-arm waypoint clocks | 200 × 16 |
| `yam_arc_grid/earbuds_20261020_standard_dp` | Conditional U-Net and DDIM100 | 100 × 14 |

Both observe front, left-wrist and right-wrist RGB plus 14D proprioception,
use native 100-frame windows at 30 Hz, seed 42, batch 32, and 240,000 optimizer
steps. The requested execution uses one Lambda H100 per run.

Supply `earbuds_distance_m=0.209882856686044` to both recipes. This is the
pooled median of both arms' XYZ path lengths across every training-frame
anchor: 411,193 anchors per arm, 822,386 distances total. Each window contains
100 native samples and 99 intervals, with repeat-last padding at episode tails.
No validation distance contributes to D. DP uses D only for matched geometry
metrics; its action chunk remains the native 100 time-indexed rows.

The generated dataset was checked against exact read-only SQL membership and
all 334 episodes' root metadata and physical commanded-pose array chunks.

This compares complete model recipes. ARC uses ImageNet-initialized image
stems, AdamW weight decay `1e-4`, 10,000-step warmup from `1e-5`, and a cosine
floor of `1e-5`. Standard DP uses unpretrained visual cores, weight decay
`1e-6`, 500-step warmup from `1e-12`, and a zero cosine floor. Both peak at
`1e-4`; the image augmentations and model capacities also differ. The pair
does not isolate the effect of action tokenization.

Absolute-clock decoding constrains moving intervals by the existing 5 m/s
maximum instead of allowing isotonic repair to collapse distinct supports
onto the same timestamp. Encoding is unchanged. XYZ-only ARC still cannot
fully preserve stationary wrist/gripper changes or leading arm start delays;
the repair does not claim to resolve those representation limits.

The source and recipes require a real optimizer-plus-scheduled-validation
smoke under the exact runtime before full training. Resolve output paths,
storage, checkpoint retention, model parameter counts and Lambda scheduler
bindings in the launch receipt; this document is not launch-readiness proof.
